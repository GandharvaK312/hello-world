## Hello World - Version Control Basics

This repository is my first version-controlled project, created for the Portfolio Building course (B25CS0311). It serves as a foundational artifact demonstrating the setup of my development environment and basic Git/GitHub workflows.

### Contents

This repository contains basic programs that print "Hello World!" to the console, written in three different languages to verify my local compiler and interpreter configurations:

* [`hello.cpp` - C++ implementation](./hello_world.cpp)
* [`hello.java` - Java implementation](./hello_world.java)
* [`hello.py` - Python implementation](./hello_world.py)
